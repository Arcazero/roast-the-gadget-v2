One original line roasting a gadget used every day — an entry for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5 in USDC).

## The roast

> My wireless earbuds die one at a time, like a buddy-cop duo where one partner retires mid-chase.

96 characters, one line. The full line also lives in `roast.txt`.

## Run it

```sh
python3 main.py
```

`main.py` reads the line from `roast.txt` and writes it byte-identically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
